# Interactions

Patterns from GitHub storefronts (haptic add-to-cart, cart bounce, status chips) kept Apple-quiet for low-end phones.

## Customer
- Add piece flashes **Added** and the bag pops
- Phone buzzes on add (if the device allows)
- Product photo shine + lift on desktop hover; tap opens studio spin
- Low stock shows **Only N left**
- No GPS. No confetti.

## Staff
- Open / Closed pill at the top
- Orders: Open / All / Delivered / Cancelled + search
- Stage bar on each order
- Product list shows the packshot and low-stock in red
